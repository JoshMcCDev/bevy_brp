Execute any BRP method registered on a running Bevy app.

The tool calls rpc.discover on the selected port, requires an exact method-name match, then forwards
the caller-supplied params as raw JSON. It remains the compatibility escape hatch for applications
that do not install BrpExtrasPlugin or publish an agent catalog.

Use brp_execute_agent_tool instead when an application publishes agent-safe catalog entries through
brp_list_agent_tools. Direct HTTP JSON-RPC is a developer-only alternative outside MCP.
